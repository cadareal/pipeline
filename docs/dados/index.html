Baixe os números, confira os lacres

Cada página do site nasce de um arquivo JSON gerado pelo pipeline, a partir de relatórios oficiais baixados por programa. Os arquivos estão aqui para download, com a lista das fontes e o lacre de cada original: uma impressão digital (hash SHA-256) que prova que o arquivo usado é o que a fonte publicou naquele dia.

O JSON do recibo tem, para cada linha, a consulta exata que gerou o número, a fonte, o filtro e os lacres. Versão da especificação: 0.9.1.

Lacres dos arquivos originais

Para conferir um lacre: baixe o mesmo arquivo da fonte (ou use o guardado no repositório), calcule o SHA-256 (no Windows, certutil -hashfile arquivo SHA256; no Mac e no Linux, shasum -a 256 arquivo) e compare. O pipeline normaliza a resposta da API antes de calcular (ordena as linhas), por isso o hash é do arquivo canônico guardado em data/raw, que o repositório descreve.

O código

Pipeline em Python, aberto (MIT): baixa, lacra, transforma, confere e publica. https://github.com/cadareal/pipeline

Refazer em casa

Com o repositório no seu computador: uv run recibo run --exercicios 2025 refaz os números e uv run recibo site refaz estas páginas. Os detalhes estão no README.

Encontrou um erro?

Diga qual número e qual fonte. Toda correção aceita entra no histórico da metodologia.
